# 🌌 TAPESTRIA (বর্ণচিত্র) — Text-to-Infinite Scrollable Image Engine

> **A revolutionary web platform that transforms natural text narratives into continuous, seamless, scrollable visual living tapestries.** 

Instead of generating conventional four-cornered static images, Tapestria dynamically computes canvas depth from narrative volume, synthesizing an infinite 2.5D parallax visual journey with zero external plugins or extensions.

---

## ✨ Features

- 📜 **Text-Driven Canvas Depth:** Scroll height dynamically expands based on word count and narrative chapters.
- 🎨 **Seamless 2.5D Parallax Canvas:** Multi-layered procedural landscape engine with celestial sky, distant horizons, anchored landmark architectures, and foreground silhouettes.
- 🌌 **5 Curated Living Worlds:**
  - **Cyberpunk Odyssey:** Neon megacity towers, hologram grids, and flying lights.
  - **Mystic Forest:** Bioluminescent ancient trees, hanging vines, and fireflies.
  - **Deep Cosmos:** Nebulae, orbital planetary rings, and levitating crystal portals.
  - **Ancient Myth:** Desert dunes, golden pyramids, sunburst rays, and hieroglyphic shrines.
  - **Ocean Abyss:** Coral towers, luminescent marine life, and rising light bubbles.
- 🗺️ **Interactive Story Minimap:** Real-time navigation strip and viewport tracking.
- ⚡ **Cinematic Autoplay:** Automated smooth scroll with 1x, 2x, 3x speed controls.
- 🎵 **Web Audio Ambient Soundscape:** Procedurally generated spatial ambient drones.
- 💾 **High-Res Export:** Stitches and exports the entire continuous vertical tapestry to PNG.
- 🔬 **WebGL vs. SVG vs. Canvas Comparator:** Built-in modal exploring how modern rendering architectures power infinite scrolls.

## 🛠️ Local Development

Clone the repo and open `index.html` in any modern web browser or serve with:

```bash
# Using Node
node server.js

# Or using Python
python -m http.server 5050
```

Open `http://localhost:5050/` in your browser.
